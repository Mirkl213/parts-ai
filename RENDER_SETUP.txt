# Бесплатная схема Render

Используется один Web Service. Отдельный Background Worker не нужен.

Build Command:
pip install -r requirements.txt

Start Command:
uvicorn app:app --host 0.0.0.0 --port $PORT

Environment Variable обязательно:
TELEGRAM_BOT_TOKEN = токен вашего Telegram-бота из BotFather

Дополнительные PartsAPI переменные можно задать позже:
PARTSAPI_GETARTICLECROSSES_KEY
PARTSAPI_GETAPPLICABILITY_KEY
PARTSAPI_TECDOCCROSSES_KEY
PARTSAPI_VINDECODEOE_KEY

При запуске app.py автоматически запускает bot.py внутри того же Web Service.
Не создавайте отдельный Background Worker для этой версии.
