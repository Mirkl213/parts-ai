Финальная схема для одного бесплатного Render Web Service.

Build Command:
pip install -r requirements.txt

Start Command:
uvicorn app:app --host 0.0.0.0 --port $PORT

Environment Variable:
TELEGRAM_BOT_TOKEN

PartsAPI теперь вызывается правильно:
GET https://api.partsapi.ru/?method=...&key=...&параметры...

VINdecodeOE: vin
getCrosses: number
getApplicability: sku + brand
tecdocCrosses: number
